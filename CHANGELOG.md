## [3.7.23+2053] - 12.10.2026 - Blacklist с TTL
- Убран саморазрушающий reset blacklist: забаненный .87 снова выигрывал гонку. Теперь вычеркнутые сидят 10 минут, ретрай идёт только на оставшиеся (цель — .178 с настоящим Navidrome).
- Корень 410: `server: NDM NDNS`, `x-detail: Unknown Name` — запросы уходили в облако Keenetic вместо домашнего Navidrome (гонка TCP выбирала ближайшее облако .87 за 21мс, настоящий дом на .178).
- Blacklist IP с чужим 410 на сессию + один повтор запроса (уходит на настоящий дом). Ретрай помечен `_ndnsRetried`, зацикливания нет; если вычеркнуты все — blacklist сбрасывается.
- Лог тела и заголовков 4xx/5xx (первые 400 символов): ищем кто отдаёт 410 только приложению.
- KeenDNS ротирует A-записи, одна (.185) протухла: параллельная гонка TCP по всем IPv4, первый ответивший побеждает (~4с вместо 20с+таймаут). Каждая попытка пишется в лог (`[Net] OK/FAIL ip:port ms`).
- Диагностика щупает все IPv4, а не первый попавшийся.
- Причина виса на MTS/work-WiFi: дефолтный lookup упирался в битый IPv6 (AAAA) и висел до 30с таймаута, хотя IPv4 жив (ping 0% потерь, ПК на чистом v4 летал за 0.9с).
- `HttpClient.connectionFactory`: резолвим IPv4 отдельно и идём по ним; фолбек — как обычно (не ломаем v6-only). Покрыты оба пути Dio (дефолт + кастомный SecurityContext), иначе серт-конфиг затирал фабрику.

## [Unreleased] - бесшовный офлайн->онлайн (12.10.2026)

### Почему требовался рестарт
- `_serverOfflineMode` ставился разово в `MainScreen.initState`, `initialize()` выходил раньше (`_isInitialized`), экраны грузились один раз без ретри. При возврате сети поиск/артист оставались в офлайне.

### Что сделано
- `OfflineService`: широковещательные `addOnlineListener/removeOnlineListener` (одиночный `onOnlineRestored` для auth оставлен).

- Поиск: офлайн fast-path — сразу кэш+локальное без висящих запросов; онлайн — как раньше (сервер→кэш). Залипания нет (вызов per-keystroke).
- `MainScreen`: синк флага при смене сети + кнопка «Проверить соединение» в оранжевом баннере (`retryConnection` + `refreshOnline`).
- `Player`: мгновенный лёгкий рефреш вместо тяжёлого `refresh()` через 5с; стрим не рвётся.
- `ArtistScreen`: добивка из кэша при пустой сети, флаг `_loadFailed/_fromCache`, кнопка «Повторить», автодогрузка по возврату сети, хинт «Офлайн — показано сохранённое».
